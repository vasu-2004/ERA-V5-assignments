S1 · 1

Activations exist for a reason

Claim. A model with no nonlinearity can only draw a straight boundary, so it cannot separate two concentric rings. Add one ReLU hidden layer and it can wrap the ring.
Build. ~300 noisy 2-D points — inner ring = class 0, outer ring = class 1 (not linearly separable). Train (a) a single linear layer + sigmoid, (b) one ReLU hidden layer.
Proof. The linear boundary is a straight line stuck near ~55%. The ReLU boundary wraps the ring to ~99%. Only the activation changed.

Takeaway. Flip the ReLU switch off: model B becomes a stack of linear layers and its boundary snaps back to a straight line, right next to model A. The capacity was always there — the nonlinearity is what lets it bend.
Why a linear model can only draw a line

A linear layer computes z = w·x + b. Its decision boundary is the set where z = 0 — a single hyperplane (a straight line in 2-D). A closed ring boundary is not a line, so no single hyperplane can separate inside from outside. A ReLU hidden layer gives you a sum of many "hinges" (max(0, wᵢ·x + bᵢ)) that can be composed into a curved, closed region.

S1 · 2

Depth without nonlinearity is a lie

Claim. Five stacked linear layers collapse to a single linear map, so a 5-layer linear net is no stronger than 1 layer. Both fail the ring identically. Insert ReLUs between the same five layers and it suddenly solves it.
Build. Same ring data; train 1 linear layer, 5 linear layers (no activations), and 5 layers + ReLU.
Proof. The 1-layer and 5-linear boundaries are the same line at the same accuracy. ReLU breaks the tie. And the five weight matrices multiply into one matrix.

Takeaway. Composing linear maps is still a linear map: W₅(W₄(…W₁x)) = (W₅W₄W₃W₂W₁)x. Stacking depth buys you nothing until a nonlinearity sits between the layers. Depth is only powerful because of the activations.
The one-line proof

Let each layer be hᵢ = Wᵢ hᵢ₋₁ + bᵢ with no activation. Substituting repeatedly, the output is W_eff x + b_eff where W_eff = W₅W₄W₃W₂W₁ — a single matrix, shown above. Any number of linear layers is exactly one linear layer, so it can never beat the 1-layer model.

S1 · 3

Embeddings learn similarity from nothing but next-token

Claim. Trained only to predict the next token in a tiny synthetic grammar, the embedding table clusters related tokens — even though similarity was never supplied.
Build. A toy language with categories (animals: cat dog cow; fruits: apple mango grape; verbs: eat chase see) and templates, so same-category tokens share next-token distributions. Train a tiny embedding→softmax model.
Proof. Project the learned embeddings to 2-D — same-category tokens land together, and every token's nearest neighbour is same-category.

Takeaway. Nobody told the model that cat and dog are alike. It discovered it because they appear in the same slots and predict the same next words. Similarity emerged from next-token statistics — the whole premise behind word2vec and modern LLM embeddings.
Why shared context ⇒ shared embedding

The model turns a token into logits via logits = E[token]·W + b. Two tokens that must produce the same next-token distribution need to land on nearly the same logits, which pushes their embedding rows E[·] toward each other. Distributional similarity in, geometric similarity out.

S1 · 4

Memorization vs generalization — and data closes the gap

Claim. A high-capacity model on tiny data drives train accuracy to ~100% while held-out accuracy stays low. Growing the dataset closes that gap.
Build. A learnable noisy 2-D classification with a held-out test split; train the same over-parameterized ReLU net at train sizes 20, 200, and 2000.
Proof. The train/test gap is huge at n=20 (train→100%, test poor) and shrinks as data grows. The gap-vs-size curve trends straight down.

Takeaway. Same model, same capacity — the only thing that changed is how much data it saw. At n=20 it memorizes (wiggly boundary, big gap); at n=2000 it generalizes (smooth boundary, tiny gap). This is the course's north star: data is everything.
Why more data closes the gap

An over-parameterized net can fit any labelling of a tiny set, including its noise, so train accuracy hits 100% while the boundary contorts around individual points — that contortion doesn't match unseen data, so test accuracy lags. More samples constrain the boundary toward the true structure, shrinking the train−test gap. Capacity enables memorization; data forces generalization.

Glossary

Linear map
A transform x ↦ Wx + b. Its decision boundary is always a flat hyperplane (a line in 2-D).
Activation
A nonlinear function (ReLU, sigmoid, tanh) applied between layers. Without it, depth collapses.
Decision boundary
The surface where the model switches its predicted class — the shaded fronts in the plots.
Embedding
A learned vector per token. Geometry (distance/angle) encodes learned similarity.
Softmax
Turns raw scores into a probability distribution over classes/tokens.
Generalization gap
Train performance minus held-out test performance. Large = memorizing.
