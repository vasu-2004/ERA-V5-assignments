How

How it works (and the "secret sauce")

Byte-level base. The 256 raw byte values are all base tokens, so every character in any page is encodable — UNK is structurally impossible (verified above). This alone satisfies the zero-UNK rule.
Merges cross punctuation & spaces. We use a byte-level pre-tokenizer with use_regex=False, so BPE can learn tokens that span markup like ](/wiki/ or India). That's the "markdown secret sauce": the extra [ ] ( ) / characters get absorbed into merges instead of exploding the token count — solved by tokenizer design, not by deleting characters. Encoding stays exact (lossless roundtrip).
The \w+ denominator quirk. The score's denominator is len(re.findall(r"\w+", text)). Python's \w excludes Devanagari/Telugu vowel signs (Unicode marks), so it splits words like भारत → भ, रत — roughly doubling Indic "word" counts. We measure with the exact same rule (verified identical in JS), so our numbers match the grader's formula.
Weighted training. A single 10,000-token vocab is trained on all four languages with per-language weights (English up-weighted to pull its fertility under 1.2, Telugu up-weighted because it's hardest). Weight = corpus repetition, identical to weighted-pair-frequency BPE. Search found w = (En 7, Hi 1, Te 2, Mr 1).
Why weighting alone isn't enough (the real lever)

With a standard GPT-2-style byte-level tokenizer (punctuation split into its own tokens), English fertility floors around 1.50 on this text and cannot reach 1.2 at any weighting — an English-only tokenizer using the whole 10k vocab still gives ~1.50, and even unlimited vocab floors at ~1.37, because commas/parens/periods each cost a token while \w+ ignores them. The dominant lever is the use_regex=False pre-tokenizer that lets those punctuation characters merge into adjacent tokens. Language weighting is the fine-tuning on top that equalizes the four fertilities.

from tokenizers import Tokenizer; import re tok = Tokenizer.from_file("tokenizer.json") text = open("english_india.txt", encoding="utf-8").read() print(len(tok.encode(text).ids) / len(re.findall(r"\w+", text))) # -> English fertility
